# Students-mental-health-analysis
A SQL project using PostgresSQL to analyze the mental health of international student.

### The problem
How the lenth of stay impacts the average mental health diagnostic scores fo the international students present in the student.
### Aim
Return a table with nine rows and five columns. The five columns should be aliased as; stay, count_int, average_phq, average_scs & avaerage_as in that order.
